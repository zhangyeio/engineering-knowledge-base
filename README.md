# Engineering Knowledge Base

企业级系统架构、数据安全与 AI 应用知识库。

这里沉淀我在企业级系统建设、数据安全、大模型应用与数字化转型中的学习笔记、实践方法和案例复盘。内容以可复用、可验证、可持续更新为目标。

## 知识地图

- [系统架构](architecture/)：分布式系统、集成架构、稳定性与可观测性
- [数据安全](data-security/)：数据传输、加密、权限、审计与合规
- [AI 应用](ai-applications/)：大模型应用、RAG、Agent、评测与工程化
- [数字化转型](digital-transformation/)：业务分析、平台建设与组织协同
- [案例复盘](case-studies/)：经过脱敏处理的项目经验、决策与教训

## 内容原则

1. **问题导向**：从真实问题出发，说明背景、约束和目标。
2. **证据优先**：关键数据和技术结论尽量标注来源、版本与日期。
3. **可复用**：提供架构思路、检查清单、模板或示例。
4. **保护隐私**：不公开客户名称、内部地址、账号、密钥及敏感业务数据。
5. **持续修订**：技术结论会随实践和行业变化更新。
